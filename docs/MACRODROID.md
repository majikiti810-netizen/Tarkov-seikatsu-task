# MacroDroid 連携メモ（2026-10-13 時点）

アプリ（ブラウザで動く PWA）は、スマホのアラームを**自分でセットすることはできません**。
そこで MacroDroid に「時刻」と「開くリンク」を渡して、アラームや通知は MacroDroid 側で出す、という分担にします。

## アプリ側にあるもの

- 設定（⚙）→「MacroDroid連携（アラーム用の予定一覧）」
  - 今から48時間の時刻つき項目（服薬・時刻つきの毎日の必須・期限・予定）を一覧表示
  - 「テキストをコピー」: `2026-10-14 08:00  服薬: ビタミン 1錠  https://…#/alarm?id=…` の形
  - 「JSONをコピー」: `[{ "id", "title", "time": "YYYY-MM-DDTHH:MM", "type", "url" }]`
    - `type`: `med` / `daily` / `deadline` / `deadline-3h` / `event`
  - 「リンクをコピー」: いま選んでいる任務を直接開くリンク
- 直接開くリンク: `https://tarkov-seikatsu-task.maru9thiruno0405.workers.dev/#/alarm?id=<任務ID>`
  - 服薬は `#/alarm?id=med` でも服薬の任務が開きます
  - 開くと、その任務の詳細が表示されます（確認済み: PC の Chrome / スマホ幅のテスト）

## MacroDroid でのやり方（いちばん簡単な順）

### 1. 毎日決まった時刻のもの（服薬・毎日の必須）
時刻が毎日同じなので、一度作れば終わりです。

1. マクロを追加 → **トリガー**「日付/時刻」→「曜日/時刻」で時刻を指定（例 08:00、毎日）
2. **アクション**「通知を表示」（タイトル例: 服薬）
3. **アクション**「Webサイトを開く」（または「URLを開く」）に、上の直接開くリンク（`#/alarm?id=med`）を入れる
   - アラーム音で起こしてほしい場合は「アラームを設定」系のアクション（Android の時計アプリに渡す）でも可

### 2. 期限付き・予定（日によって変わるもの）
今のところは**手動**です。MacroDroid連携画面のテキストを見て、必要なものだけ MacroDroid の「1回だけ」のトリガーを作ってください。

## 正直な注意点

- MacroDroid のメニュー名はバージョンや言語設定で少し違うことがあります。上の名前は目安です（作者はこの端末で MacroDroid 側の操作は確認していません）。
- アプリの一覧を MacroDroid が**自動で読み取る仕組みはまだありません**（アプリはスマホの中だけで動いていてサーバーがないため）。将来、同期用のサーバー（Supabase）を入れたら、MacroDroid の「HTTPリクエスト」で一覧を取ってくる形にできます。
- アプリ内の通知（服薬・毎日の必須・期限24時間前/3時間前）は、**アプリを開いている間だけ**届きます。閉じていても届く通知は MacroDroid 側か、将来の Web Push で対応します。
